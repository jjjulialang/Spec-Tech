# Extreme hidden-set fixture

This deterministic fixture extends the practice-dataset pattern with four
multi-page construction PDFs, exact answer-key metadata, structured-extraction
sidecars matching the ACELAB assets pack, revision-history traps, substring tag
collisions, equivalent-unit distractors, a landscape schedule, and an
image-only slightly rotated field-detail page.

The fixture is generated at test time. It never makes network requests and its
manifest/structured sidecars must be ignored by production PDF discovery.
